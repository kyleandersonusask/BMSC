## Parts

| Part | Version | Licence | Where | Use |
|---|---|---|---|---|
| uPlot | 1.6.32 | MIT | `lib/vendor/uplot-1.6.32/` (`uPlot.iife.min.js`, `uPlot.min.css`, `LICENSE`) | occupancy-over-time chart and binding curve |

- Both are **unmodified** npm browser builds. The fetch and integrity record is in `lib/vendor/README.md`, and the SHA-256 of each
  file is in `lib/vendor/SHA256SUMS`.
- They are inlined into `index.html` with `python tools/inline.py demos/hlh-dimer-ebox/src.html demos/hlh-dimer-ebox/index.html`.
  Each inlined block starts with a comment `/* inlined: lib/vendor/... */`.
- The MIT notices travel with the inlined code. Keep each library's licence header, or add the `LICENSE` text as a comment
  beside it.
- Shared model: `model.json`, generated by `model/gen_model.py` (the science intern, 2026-10-11). Every take must read its
  numbers from it.
- Builders add any set component (`theme/file`), remix or `lib/` part they use to this table.
